# Changelog

## 0.3.0 — 2026-10-30

- Adapted the original cube logo for Android splash safe areas, removing the black square backplate while preserving the full cube shape.
- Rebuilt the in-app loading screen with a branded midnight gradient, animated orbit, breathing logo, reveal motion, and loading indicator.
- Added a soft animated ambient wash and timing progress halo, plus a clearer, tappable scramble card.
- Redesigned the bottom navigation with animated active pills and labels.
- Refreshed Stats backgrounds and card shapes, with animated stat-value updates.
- Fixed timer-stat collisions on narrow layouts and at larger system font scales.
- Updated Android version code to 3 and version name to 0.3.0.

This is a debug-signed APK for review and installation. The Android port remains in progress; see `docs/PORTING_STATUS.md`.

## 0.2.0 — 2026-10-30

- Added a Stats dashboard with current/best averages, best single, trend and distribution charts.
- Added persistent Appearance settings for gradients, graph glow and animation, and system/dark appearance.
- Added animated page and scramble changes, responsive timer sizing, and compact screen improvements.
- Updated Android version code to 2 and version name to 0.2.0.
