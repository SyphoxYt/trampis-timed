# Changelog

## 0.2.0 — 2026-10-30

- Added an animated in-app startup screen showing the original CubeTime app-icon image.
- Redesigned Stats as a dashboard with current and best averages, best single, selectable time trend, and solve distribution.
- Added persistent Appearance settings for static/dynamic stat gradients, graph glow and animation, and system/dark appearance.
- Added slide/fade page changes, animated scramble updates, and a responsive timer readout.
- Adjusted timer widgets and statistics cards for compact screens and larger system text.
- Updated Android version code to 2 and version name to 0.2.0.

This is a debug-signed APK for review and installation. The font weight/casualness/cursive options are still preview-only, and the Android port remains in progress.
