# Changelog

## 0.4.0 — 2026-10-30

- Removed the separate Android system splash artwork; startup now flows into the in-app loading screen.
- Added persistent bold timer digits and selectable blue, violet, mint, and amber accent palettes.
- Added staggered Stats-card entrances, an Appearance toggle for card motion, and animated distribution bars.
- Replaced Appearance preview-only font sliders with a real bold timer setting.
- Updated Android version code to 4 and version name to 0.4.0.

This is a debug-signed APK for review and installation. The Android port remains in progress; see `docs/PORTING_STATUS.md`.

## 0.3.0 — 2026-10-30

- Reworked startup and in-app presentation with an animated cube logo, timer glow, progress halo, and scramble card.
- Redesigned navigation and Stats card styling, with animated stat values.
- Fixed timer-stat collisions on narrow layouts and at larger system font scales.
- Updated Android version code to 3 and version name to 0.3.0.
